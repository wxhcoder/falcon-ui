# Overview SVG Style Design

## 背景

组件总览页的预览图需要统一为参考图风格：深色页面上展示蓝灰色的抽象
组件符号。第一阶段只定义 SVG 视觉规范，不修改现有文档页面、组件源码或
正式 `docs/public/overview/*.svg` 文件。

当前风格已通过 `FlButton`、`FlInput`、`FlTable` 三个临时样稿验证。

## 目标

- 让每个组件预览图在总览页中保持统一、精致、轻量的视觉语言。
- 预览图只表达组件的核心识别特征，不复刻完整业务 UI。
- 输出可直接落地到 `docs/public/overview/*.svg` 的规则。
- 后续新增或重绘 SVG 时，能够按同一套尺寸、颜色和间距执行。

## 非目标

- 不改总览页布局和 `OverviewGrid` 组件。
- 不改组件实现、主题样式或示例代码。
- 不要求每张 SVG 复刻真实组件所有状态。
- 不在每个预览图中强制加入箭头、圆点或标签。

## 画布与背景

- SVG 画布沿用总览页现有比例：`width="248"`、`height="144"`。
- `viewBox` 使用 `0 0 248 144`。
- SVG 内部不绘制灰色或深色背景。
- 图形应可在深色页面或深色卡片背景上直接展示。
- 图形主体应位于画布视觉中心，避免贴边。

## 色彩

主蓝从参考图中抽样，统一使用：

- 主蓝：`#0083FF`
- 蓝色高光：`#1E96FF`
- 蓝色暗部：`#0068C8`

中性色使用冷灰系：

- 主要灰：`#9AA1AA`
- 辅助灰：`#8C929B`
- 深灰线：`#6F7781`
- 浅灰高光：`#BCC3CB`

颜色使用规则：

- 主交互区域、激活块、表头等使用 `#0083FF`。
- 次要结构使用灰色。
- 同一张 SVG 中蓝色元素数量要克制，优先突出一个核心区域。
- 不使用大面积渐变背景。
- 可使用轻微线性渐变表现高光，但渐变必须围绕主蓝或冷灰。

## 圆角与描边

- 主要矩形圆角统一使用 `rx="4"`。
- 小尺寸内部条块可使用 `rx="3"`。
- 极细竖线可使用 `rx="1"`。
- 主要线框统一使用 `stroke-width="1"`。
- 不使用粗描边营造重量感。
- 外框、分隔线和状态线的视觉重量应低于蓝色主体。

## 尺寸与内边距

图形应遵守统一内聚原则：

- 横向组件主体推荐高度为 `36px` 左右。
- 大型结构组件可略高，但内部内容要按统一 padding 排列。
- 同一容器内的左右 padding 必须一致。
- 同一容器内的上下 padding 必须一致或形成明确的等距节奏。
- 表格、树、列表等结构图形中，每列或每层内容应以自身区域居中。
- 同类内容块宽高应保持一致，除非需要表达层级或状态差异。

`FlTable` 样稿的基准规则：

- 外框：`x="31"`、`y="36"`、`width="186"`、`height="72"`。
- 表头高度约 `25px`。
- 表体每列内容水平居中。
- 表体左右内边距统一为约 `15px`。
- 表体两行内容保持固定垂直间距。

## 抽象程度

每张 SVG 只保留组件最容易识别的特征：

- `FlButton`：蓝色按钮主体，可保留 `Button` 文本。
- `FlInput`：灰色输入框主体，内部使用蓝色输入片段提高对比。
- `FlTable`：蓝色表头、细线网格、灰蓝内容块。
- 表单组件优先表达输入区域、状态块、清空或选择暗示。
- 数据展示组件优先表达结构、分组、层级或网格。
- 反馈浮层组件优先表达浮层容器、头部、内容和操作区。

除非组件本身需要，不默认加入：

- 箭头
- 圆点
- 外部说明文字
- 卡片背景
- 复杂阴影

## 文本规则

- 只有组件识别需要时才在 SVG 内使用文字。
- `FlButton` 可以保留 `Button` 文本，因为按钮文本是核心识别元素。
- 其他组件优先使用图形表达，避免重复总览卡片标题。
- 文本使用白色或近白色，保持可读但不成为唯一识别方式。

## 导出规则

- 每个正式 SVG 只包含必要的形状、渐变和 `title`。
- `title` 使用组件名，例如 `FlButton SVG preview`。
- 不内嵌 CSS，不依赖外部字体，不引用外部资源。
- `fill="none"` 可保留在根节点，具体图形显式声明 fill 或 stroke。
- 渐变 id 必须按组件命名，避免多个 SVG 合并时冲突。

## 验收标准

- 在深色背景上查看时，图形清晰但不过重。
- 主蓝与参考图一致，主蓝为 `#0083FF`。
- SVG 内部没有额外灰色背景卡片。
- 主要圆角为 `4px`，主要描边为 `1px`。
- 内部元素的上下左右 padding 统一。
- 每张图都能在缩放到总览卡片尺寸时保持识别度。
- 同一批 SVG 的视觉重量、尺寸感和抽象程度一致。

## 后续执行

确认此规范后，再按规范重绘 `docs/public/overview/*.svg`。第一批可先覆盖
`FlButton`、`FlInput`、`FlTable`，验证总览页展示效果后再扩展到全部组件。
